# Simple Interest Calculator

## Description
This project contains a Bash script that calculates **simple interest**
based on user input. It is a simple command-line calculator designed to
demonstrate basic scripting and arithmetic in Bash.

## Features
- Takes user input for principal amount, rate of interest, and time period
- Validates that inputs are numeric
- Calculates and displays the simple interest

## Input Fields
- **Principal** — the initial amount of money
- **Rate of Interest** — annual interest rate (in %)
- **Time Period** — duration in years

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## How to Run
```bash
chmod +x simple-interest.sh
./simple-interest.sh
```
